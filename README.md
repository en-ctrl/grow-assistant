# 種菜小幫手 Green Buddy

## 使用方式
1. 將 `index.html` 上傳到 GitHub Repository 根目錄。
2. 進入 Repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 `Deploy from a branch`。
4. Branch 選 `main`、資料夾選 `/(root)`，按 Save。
5. 等待 GitHub Pages 部署完成，使用頁面顯示的網址開啟網站。

## 功能
- 首頁顯示今天日期與進行中作物的目標日期倒數（最近的排最前面）。
- 月曆標記有紀錄的日期；點擊日期後，會顯示該日的紀錄。目標日期與紀錄日期都會列入當日內容。
- 新增作物紀錄：作物、目標日期、紀錄日期、澆水提醒開關、備註、圖片。
- 查詢進行中、所有、已結束紀錄；已結束作物不會出現在首頁倒數清單。
- 資料儲存在目前瀏覽器的 localStorage。

## 注意
此版本的「提醒澆水」是紀錄提醒設定狀態，尚未加入背景推播或跨裝置同步。圖片與紀錄存在目前瀏覽器中；清除網站資料或更換裝置／瀏覽器可能造成資料無法取回。建議定期備份。
